# ChronoFamille V3 — 100% FONCTIONNEL

## 🚀 Fonctionnalités actives :

### 🔒 Verrouillage réel
- Définir un temps → l'application se verrouille
- Déverrouillage manuel possible
- Le verrou expire automatiquement

### 🏫 Mode École Automatique
- Se déclenche Lun-Ven 8h-12h / 14h-17h
- Verrouille l'écran automatiquement
- Peut être activé/désactivé à tout moment

### 📩 Demandes de temps
- L'enfant peut demander du temps supplémentaire
- Le parent voit la demande et accepte/refuse
- Historique des demandes conservé

### 💬 Messages pré-remplis
- Réponses rapides pour l'enfant

### 📱 Service en arrière-plan
- Surveille en permanence
- Redémarre automatiquement au démarrage du téléphone
- Notification de service permanente

### 💾 Données persistantes
- Tout est sauvegardé localement
- Rien ne se perd quand on ferme l'app

---

## ⚠️ Permissions à accorder au premier lancement :
1. **Afficher par-dessus les autres applications** → Pour le verrouillage
2. **Accéder aux données d'utilisation** → Pour surveiller le temps
3. **Accès à la politique de notifications** → Pour le mode silencieux

---

## ✅ Mode d'emploi :
- **Onglet Parent** : Contrôler le temps, verrouiller/déverrouiller, voir les demandes
- **Onglet Enfant** : Voir son temps restant, demander du temps
- **Icône Paramètres** : Accorder les permissions nécessaires
